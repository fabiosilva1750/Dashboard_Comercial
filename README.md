# 📊 Dashboard Comercial

Este dashboard foi desenvolvido em **Power BI** para análise de performance comercial, trazendo insights sobre faturamento, vendas e desempenho de produtos e vendedores.

## 🔎 Principais Métricas
- **Faturamento Total**  
- **Quantidade Vendida**  
- **Ticket Médio Geral**  
- **Ticket Médio por Produto**  
- **Faturamento por Produto**  
- **Evolução do Faturamento (séries temporais)**  

## 📑 Estrutura do Dashboard
- **Aba 1 – Visão Geral**  
  - Faturamento  
  - Quantidade vendida  
  - Ticket médio  
  - Ticket médio por produto  
  - Faturamento por produto  
  - Evolução do faturamento  

- **Aba 2 – Ranking de Performance**  
  - **Top 10 Produtos mais vendidos**  
  - **Top 10 Vendedores com maior faturamento**  

## 🛠️ Funcionalidades
- Filtros dinâmicos para refinar a análise  
- Visão clara de desempenho por produto e por vendedor  
- Acompanhamento de evolução ao longo do tempo  

## 🚀 Objetivo
O dashboard foi desenvolvido para fornecer uma visão estratégica das vendas, apoiando a gestão comercial e auxiliando na identificação de oportunidades de crescimento.
